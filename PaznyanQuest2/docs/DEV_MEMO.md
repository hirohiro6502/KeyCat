# 開発メモ(パズにゃんクエスト２)

作業の前にこのファイルを読むこと。仕様が変わったらここも更新する。

## 方針

- 1作目(PaznyanQuest-HTML)の続編。**1作目のドット絵は使わず、絵はすべて新規**(`js/art.js` でコードから描く)。
- 音も外部ファイルを使わず Web Audio で合成(`js/audio.js`)。BGM:title / map / puzzle / bonus / tower。
- 画面は 16:9 固定。PC は全画面、スマホは横画面(縦にすると「よこむきにしてね」)。
- 画面に出す文字は読みやすい区切りで `\n` を入れる(1作目と同じルール)。文言は `js/i18n.js` に4か国語で書く。
- 言語は `localStorage` の `pq2_lang` に記憶。はじめての起動のときだけ言語選択を出す。
- セーブは3枠(`pq2_save0..2`)。クリア・宝箱は自動セーブ。マップのメニューからも保存できる。
- ビルド不要の素の HTML。`file://` でも動くよう ES モジュールや fetch は使わない。

## テーマ:「持ち上げる」

- 1マス単位の移動。高さの概念あり:**マスの高さ = 地形(床0 / ブロック1 / 高ブロック2)+ 積んだ物の数**。
- 低いマスへは歩いて降りられる。登るのはスカイニャンのジャンプ(+1段まで)だけ。
- 物は最大2段まで積める。持ち上げのルール(`js/logic.js` の act):
  - **自分のほうが高い** → いちばん上だけ取れる(2段の上段は高所からしか取れない)
  - **同じ高さ(地面)** → まとめて持てるなら全部、持てなければ**下段を抜き取る**(上の物は1段落ちる)
  - 置くときは手のいちばん上の1つずつ
- 重さ:カギ1・木箱2・鉄球2(重い)。ふつう/スカイ=重さ2まで・重い物は不可。パワー=重さ4まで・重い物も可
  → カギは2本重ねて運べる。パワーニャンだけ2段まとめ持ち・鉄球が持てる。
- 何か持っているとジャンプできない。
- コスチュームはステージ内の着替えマットに乗ると変わる(切り替えのタイミングがパズルになる)。

## 持っている間だけ変わる世界

- 封印床(1/2/3):その色のカギを持っている間だけ見えて渡れる。上で手放すことはできない。物は置けない。
- 宝箱($):宝カギを持っている間だけ現れる(現れている間は通れない)。開けるとダイヤ+30、すぐセーブ。クリア不要。
- 風(< > ^ v):鉄球を持っていなければ飛ばされる。

## そのほかのしかけ

スイッチ床(+)・重さ床(W:物を2段積むと反応)→ 部屋の扉(D)が開く。階段(legend の to)で別の部屋へ。
ドミノ(d)を押すと連鎖して倒れ、1枚ごとにダイヤ+1、ベル(!)でダイヤ+20(ドミノ広場ではクリア)。

### これから足す予定(アイデア)

ベルトコンベア、昇降機、壊せる床・壁、一方通行穴、カギ合成ツボ、ワープホール、巨大カギ。

## 遊びの流れ・自由度

- パズル → 爽快パート(ドミノ広場・階段の下のボーナスエリア=ダイヤ取り放題)→ パズル、と混ぜる。
- ステージの順番はすべて自由。エリアは「前のエリアの封印塔」をクリアすると開く(それ以外の条件なし)。
- さいごの塔はクリア数で開く(いまは準備中、16 ステージ)。
- ダイヤはステージを出る・やり直す・クリアするときに合計へ加算(取り放題)。
